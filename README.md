# DES-UCB — Drift-triggered Evidence-Switching UCB

Research prototype for *"Drift-triggered evidence switching suppresses stale priors in cold-start
interactive recommendation"*.

* `DES_UCB.ipynb` — the deliverable: method, synthetic + real-data experiments, ablations, staleness
  sweep, rate check, preregistered claim registry and paper-text gate (sections 1–15). Section 15 is
  the full how-to-run, metric glossary and design-decision log.
* `des_ucb_core.py` — importable, tested helper module (estimators, evidence switch, detectors,
  BOB, DES-UCB agent, baselines B1–B9, environments, runner, metrics, claim registry, loaders).
* `tests/test_core.py` — pytest suite.
* `configs/` — `default.yaml`, one file per drift type, one per real dataset.
* `results/` — generated by executing the notebook (`claims.json`, `results_skeleton.md`, csv/png;
  parquet logs are git-ignored). `data/` holds runtime downloads (git-ignored).

## Run

```bash
python3.11 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
pytest -q                      # 17 passed, 1 xfailed (preregistered no-harm check, kept strict)
jupyter nbconvert --to notebook --execute DES_UCB.ipynb --output DES_UCB.ipynb   # ~5 min on 8 cores
ruff check .                   # lint
```

Claim verdicts live in `results/claims.json`; only bullets under *Supported* in
`results/results_skeleton.md` may be written into the paper. Failed checks are reported as
`NOT SUPPORTED`, not tuned away.

## Manuscript

LaTeX sources are in `paper/` (`main.tex` two-column, `main_onecol.tex` single-column, shared
`body.tex`). Tables and macros come from `python scripts/build_paper_tables.py`.

```bash
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
./build_docx.sh                       # main_onecol.docx (pandoc)
pip install python-docx && python build_templates.py   # DES_UCB_IJIES.docx, DES_UCB_Futech.docx
```

`build_templates.py` pours the same body into the journal Word templates kept under
`paper/templates/` (IJIES two-column format, Future Technology format), applying each
template's layout rules (fonts, caption forms, abstract limits, back-matter sections).
